# Shridhar_Kumbhar_SOC_Portfolio
A responsive, dark-themed SOC Analyst portfolio built with HTML, CSS, and vanilla JavaScript.

Run locally
Extract the ZIP file.
Open the shridhar-soc-portfolio folder in VS Code.
Open index.html in a browser, or use the VS Code Live Server extension.
Customize
Update contact details and profile text in index.html.
Add verified LinkedIn/GitHub URLs when ready.
Add project repository links when the repositories are published.
Replace assets/Shridhar_Kumbhar_SOC_Analyst.pdf with an updated resume using the same filename.
Files
index.html — page structure and content
style.css — responsive styling
script.js — mobile navigation and copy-email interaction
assets/ — resume PDF
